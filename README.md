# Orbitclean-edge-JS
OrbitClean Edge — Plataforma de monitoramento e simulação de evasão orbital autônoma de detritos espaciais utilizando Edge AI. Desenvolvido para a Global Solutions 2026 da FIAP (Engenharia de Software). Este repositório estende a interface do projeto com regras de negócio dinâmicas, controle de estados e manipulação avançada do DOM em JavaScript.
